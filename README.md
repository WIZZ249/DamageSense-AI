# DamageSense AI: Humanitarian Assessment Dashboard

**DamageSense AI** is a rapid-response tool designed for humanitarian field offices to assess structural integrity using Computer Vision. 

## Key Features
* AI-Powered Detection: Leverages MobileNetV2 for real-time infrastructure classification.
* Heuristic Damage Analysis: Automatically flags structural failure keywords (Rubble, Ruins, Wreckage).
* Pro Dashboard: Clean, Dark-Mode UI styled with Bootstrap 5.
* Database Integration: SQLite backend for persistent record keeping.

## Technical Stack
* Backend: Python / Flask
* AI/ML: TensorFlow / Keras
* Database: SQLAlchemy
* Frontend: Bootstrap 5

## Setup
1. python -m venv venv
2. .\venv\Scripts\activate
3. pip install -r requirements.txt
4. python AI-SYS.py
